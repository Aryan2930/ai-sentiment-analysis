# AI Sentiment Analysis 🤖

An AI-powered web application that analyzes the sentiment and emotional tone of user-provided text.

## Features

- Analyzes user text
- Detects sentiment/emotional tone
- Simple and user-friendly interface
- AI-powered text analysis
- Web-based application

## Technologies Used

- Python
- Hugging Face
- Transformer Models
- HTML
- CSS
- Gradio

## Project Structure

- `app.py` - Main application
- `requirements.txt` - Python dependencies
- `ui_preview.html` - UI preview
- `Dockerfile` - Deployment configuration

## How to Run

Install the required dependencies:

```bash
pip install -r requirements.txt
